# Texture Files Required

Place the following PNG files (16x16 pixels) in this directory:

1. **mob_head_dropper_iron.png** - Iron Mob Head Dropper Sword texture
2. **mob_head_dropper_diamond.png** - Diamond Mob Head Dropper Sword texture
3. **mob_head_dropper_netherite.png** - Netherite Mob Head Dropper Sword texture
4. **wither_skeleton_head.png** - Wither Skeleton Head texture
5. **blaze_head.png** - Blaze Head texture
6. **enderman_head.png** - Enderman Head texture

## Creating Textures

All textures must be 16×16 PNG files.

### For Sword Textures:
- Base the design on vanilla Minecraft swords
- Add a custom distinguishing feature (e.g., different handle color, glowing effect)
- Iron: gray/silver blade
- Diamond: cyan/light blue blade
- Netherite: dark purple/black blade

### For Head Textures:
- **Wither Skeleton Head**: Dark gray/black skeleton head (similar to vanilla but custom)
- **Blaze Head**: Yellow-orange cube with rod-like features
- **Enderman Head**: Purple/dark colored tall head shape

## Tools to Create Textures:
- Piskel (https://www.piskelapp.com/) - Free online pixel art editor
- Aseprite - Professional pixel art software
- GIMP - Free image editor
- Paint.NET - Simple free image editor

## Placeholder Textures

If you don't have custom textures yet, you can:
1. Export textures from vanilla Minecraft resource pack
2. Modify them slightly (change colors, add details)
3. Save as PNG in this directory
